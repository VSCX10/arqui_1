# 3.3. Consolidación de Escenarios

Paso 6 del QAW. Se agruparon los escenarios preliminares **repetidos o similares**: los que describen el mismo estímulo sobre la misma parte del sistema, aunque los hayan propuesto stakeholders distintos. Los stakeholders que los propusieron aceptaron cada agrupación, y los escenarios con un solo origen pasan sin cambios. Cada escenario consolidado tiene un solo atributo de calidad y su redacción ya precisa el estímulo y la respuesta. La última columna indica el código con el que el escenario quedó en la sección 2.2.
